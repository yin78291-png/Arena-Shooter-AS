# arena shooter
a unblocked game by html code
WASD move · Mouse aim · Click fire · Space jump · Shift sprint
1–6 or mouse wheel switch weapons · L gun shop · T chat

Five extra guns cost 200 points each; earn 100 points per enemy · E heals at the green station

Your name, unlocked guns, points, and leaderboard are saved in this browser.

Multiplayer works between tabs/windows of this browser using BroadcastChannel. Internet matchmaking needs a game server.
